<div>
  Required dependencies
</div>
Launching the openSERP container to interact with the engines
<ul dir="auto">
<li>sudo apt-get update</li>
<li>sudo apt-get install docker-ce docker-ce-cli containerd.io</li>
<li>docker run -p 127.0.0.1:7000:7000 -it karust/openserp serve -a 0.0.0.0 -p</li>
</ul>
<div>
  Project installation
</div>
<ul dir="auto">
<li>git clone https://github.com/perv-cell/chphone.git</li>
<li>sudo apt install python3-venv</li>
<li>python3 -m venv venv</li>
<li>source venv/bin/activate</li>
<li>pip install -r requirements.txt</li>
<li>uvicorn chphone.src.service.main:app --reload</li>
</ul>
